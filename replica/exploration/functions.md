# 原版功能与工作流

仅统计已发现的入口、状态和代表性行为分支

## 工作流

### 创建、导入并整理文库

从文献输入得到可检索、可组织的本地文库

1. 新建或导入条目
2. 编辑元数据
3. 组织分类和标签
4. 添加笔记

预期结果：条目及其元数据、分类、标签和笔记在界面中可见并保持

### 附件阅读与注释

附加并阅读本地 PDF，形成注释

1. 添加 PDF 附件
2. 打开阅读器
3. 创建高亮或笔记
4. 返回文库

预期结果：PDF 可阅读，注释和附件状态保持

### 检索、引用与导出

找到目标文献并生成可复用输出

1. 检索并选择条目
2. 执行导出或创建书目
3. 检查输出

预期结果：选中结果和导出内容符合输入

### 文库维护与偏好

处理重复、回收站、布局和本地设置

1. 检查重复条目
2. 移动/恢复回收站条目
3. 调整设置

预期结果：维护操作和设置产生可预测结果

### 同步、群组与订阅

连接 Zotero 服务进行同步与协作

1. 检查本地入口和前置条件
2. 在授权账号下验证服务流程

预期结果：账号与服务状态正确反映

### 集成、插件与自动化

连接浏览器、文字处理和开发者工具

1. 清点入口与依赖
2. 在授权外部组件下验证

预期结果：集成入口和边界明确

## item-entry · 手动新建与编辑文献条目

结论：observed
手动条目在创建/编辑后可保存；正常退出后的 SQLite 快照和重开 UI 均证明条目、分类、笔记、标签、附件及注释持久化

输入：Replica Exploration 空分类；标题 Local Replication Study；作者 Example, Ada；出版物 Journal of Local Testing；日期 2026；已保存隔离文库
输出：分类中出现 Local Replication Study，详情显示预期元数据与更新后的修改日期；完整性健康的快照；重开后相同条目、笔记与阅读注释
副作用：隔离文库条目数据写入；实时 SQLite 差分因 EXCLUSIVE 锁 blocked；新增退出状态数据库快照证据
待确认：运行中逐动作 SQLite 差分仍受 EXCLUSIVE 锁限制

- 新建并编辑普通文献：observed · 手动创建期刊文章并编辑核心元数据成功
- 退出并重开后的条目持久化：observed · 正常退出和重开后数据保持，数据库完整性及外键检查通过

## 阻塞与限制

- 取证失败：initial：原版主库连接生命周期 EXCLUSIVE 锁使运行中在线备份超时；不修改原 App，UI 流程继续，数据副作用在正常退出后补查；恢复条件：正常退出隔离实例后取得只读一致性快照；若必须运行中逐动作数据库差分，需要不改变原版的安全新取证方法
- 账号同步、群组与在线服务：隔离 profile 无账号且本轮未授权登录或联网副作用；仅记录入口，不执行同步/建群；恢复条件：用户提供专用测试账号并明确授权具体联网、同步和群组操作
- 截图像素级视觉复核：所有关键状态已保存目标窗口 JPEG，Computer Use 的 AX/文本和几何信息已核对；当前模型工具明确提示不支持图像输入，不能声称完成像素级视觉审查；恢复条件：由支持图像输入的 Agent 或用户查看保存的窗口截图，复核颜色、间距、图标和动效
- 空分类历史状态的恢复路径：新建条目第一次后快照中断，collection.empty 到后续状态没有完整动作边；已从更后面的 library.reopened 实际执行 library-reset-1 恢复 main.empty，但未重放该历史状态；恢复条件：需要逐状态恢复证明时，从保留测试数据重建空分类并记录返回/重置动作
- 空白条目历史状态的恢复路径：空白条目由异步后快照中断的创建动作产生，没有可计入 route 的后续完整反向边；后继重开状态已通过重置恢复初始，但该历史节点未单独恢复；恢复条件：从保留数据重建空白条目后记录取消/删除或重置的完整动作
- 已编辑条目历史状态的恢复路径：标签添加两次后快照中断使 item.editing.saved 到标签状态缺少正式动作边；后继 library.reopened 已通过 library-reset-1 恢复 main.empty，历史节点恢复未被单独证明；恢复条件：重建已编辑条目并记录到后继状态或初始状态的完整路径
- 单标签历史状态的恢复路径：单标签到双标签动作后快照中断，状态图缺少完整前进/恢复边；后续重置已恢复初始，但历史单标签节点未重放；恢复条件：重建单标签条目并记录取消筛选/删除标签或重置的完整路径
- 覆盖仅针对本机 Zotero 10.0.6 中文 UI、已发现入口和代表性输入，不声称穷举
- 运行中 SQLite 差分、像素级视觉审查、账号联网、外部集成、永久删除、复杂分支与部分标签添加轨迹未覆盖
- 四个历史状态缺少逐状态恢复路径，已分别登记 blocked
